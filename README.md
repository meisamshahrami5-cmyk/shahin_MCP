# Shahin MCP

یک پروژه مبتنی بر **Model Context Protocol (MCP)** برای ساخت و اجرای ابزارهای قابل استفاده توسط مدل‌های هوش مصنوعی.

## معرفی

Shahin MCP یک سرور MCP است که امکان ایجاد ابزارهای اختصاصی و اتصال آن‌ها به برنامه‌های سازگار با MCP را فراهم می‌کند.

این پروژه با **Python** توسعه داده شده و برای توسعه و آزمایش ابزارهای MCP طراحی شده است.

## امکانات

* اجرای MCP Server
* ساخت ابزارهای اختصاصی
* ارتباط با کلاینت‌های MCP
* توسعه با Python
* قابلیت گسترش برای اضافه کردن ابزارهای جدید

## نصب

ابتدا Repository را دریافت کنید:

```bash
git clone https://github.com/meisamshahrami5-cmyk/shahin.git
cd shahin
```

سپس یک محیط مجازی Python ایجاد کنید:

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

## اجرا

برای اجرای سرور:

```bash
python server.py
```

پس از اجرای موفق، سرور روی آدرس محلی اجرا می‌شود.

برای اضافه کردن یک ابزار جدید، می‌توانید کد مربوط به آن را در سرور MCP اضافه کرده و سپس سرور را مجدداً اجرا کنید.
